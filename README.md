# 君意 · 学习空间（听写助手 + AI 老师）

一个纯静态网页小站，手机上用浏览器打开就能用，**不需要服务器、不需要数据库**。

## 页面结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 首页：欢迎界面 + 两个 APP 图标（听写助手 / AI 老师） |
| `dictation.html` | 听写助手（原来的全部功能，左上角多了「← 首页」） |
| `ai.html` | AI 老师：网页版 AI 对话，能发图片和文字 |
| `assets/` | 样式、脚本、KaTeX 公式渲染 |
| `proxy/server.py` | 可选：本地小代理，解决接口跨域 + 顺便提供网页 |
| `听写助手.html` | 旧文件，保留没动，内容和 dictation.html 相同 |

打开方式：直接双击 `index.html` 就能用；接口有跨域限制时，用下面的本地代理方式打开。

# AI 老师

## 能做什么

- 发**文字**、发**图片**（截图、拍照、粘贴、拖拽都行）跟 AI 对话
- 流式输出，像豆包 / DeepSeek 官网那样一个字一个字出来
- 思考过程自动折叠，想看再点开
- 多个对话，左侧列表可以搜索、切换、删除
- 公式自动排版（KaTeX 已打包在本地，断网也能显示）
- 一键导出：Markdown / 纯文本 / 单页 HTML / 全部对话 JSON 备份

## 设置项（都在网页「设置」里填）

| 设置 | 说明 |
| --- | --- |
| 接口地址 | 填到 `/v1` 就行，例如 `https://api.deepseek.com/v1`。程序会自动补 `/chat/completions`、`/responses` 或 `/messages` |
| API Key | 你自己的 key |
| 模型名称 | 可以手填，也可以点旁边的 **「获取模型列表」** 让程序拉取清单后点选 |
| 协议 | `openai-chat` / `openai-responses` / `Anthropic` 三选一 |
| 上下文长度 | 单位 K（1K = 1024 token），**默认 500K**，用于自动裁剪旧对话 |
| 单次输出上限 | 单位 K，**默认 64K**，太小会导致只出思考不出正文 |
| 思考模式 | **off / minimal / low / medium / high / xhigh / max** 七档，OpenAI 系原样传 `reasoning_effort`，Anthropic 换算成 `budget_tokens`（1024 / 2048 / 4096 / 8192 / 16384 / 32768） |
| 温度 | 讲题建议 0.5~0.7 |
| 跨域代理 | 可选，填 `http://127.0.0.1:8787` 就走上本地代理 |

## 获取模型列表

模型名不用背：在「设置」里填好**接口地址**和 **API Key**，点模型名称旁边的
**「获取模型列表」**，程序会请求 `{接口地址}/models`，把这家服务支持的所有模型列出来。

- 列表里点一个就直接填进模型名，当前正在用的那个会带黄色竖条高亮
- 上面有搜索框，模型多的时候直接打字过滤
- `Anthropic` 协议会自动带上 `x-api-key` 和 `anthropic-version` 头
- 拉不到也别慌（有些中转站干脆没有 `/models` 接口），关掉窗口手填就行

## 数据存在哪？（纯静态网页能存对话吗）

**能。** 用的是浏览器自带的两种存储，不需要任何后端：

| 数据 | 存在哪 | 说明 |
| --- | --- | --- |
| 设置、API Key | `localStorage` | 只有几十 KB |
| 对话记录（含图片） | `IndexedDB` | 容量大，几百 MB 都没问题，图片是按压缩后的 base64 存的 |

注意事项：

1. **换浏览器、换设备、清浏览器数据，记录就没了**。重要对话请用「导出」存成文件。
2. 用无痕/隐私窗口打开，关掉窗口就清空。
3. 同一个浏览器里，`file://` 直接双击打开 和 `http://127.0.0.1` 打开算**两个不同的站点**，记录不互通。选定一种方式用就行。
4. 数据只在本机，不会上传到任何服务器（除了发给 AI 接口本身）。

## 接口跨域（CORS）怎么办

浏览器直接请求第三方 API，很多家会拦（报 `Failed to fetch`）。两种办法：

**办法一：用本地代理（推荐，最稳）**

```powershell
cd D:\python\听写助手网页版
py -X utf8 proxy\server.py
```

然后用浏览器打开 <http://127.0.0.1:8787/ai.html>，在设置里把「跨域代理」选成
`http://127.0.0.1:8787`。代理只监听本机 127.0.0.1，不保存任何内容，关掉窗口就结束。

**办法二：用支持跨域的接口**

有些中转站 / 自建网关允许浏览器直连，那就把「跨域代理」留空即可。

> 注意：HTTPS 页面不能请求 HTTP 接口，会被浏览器直接拦掉。本地测试时统一用
> `http://127.0.0.1:8787` 打开网页最省心。

## AI 老师的提示词

内置了一份「中小学老师」的系统提示词，重点要求：

- 用大白话讲，不用书面腔
- 固定六步：看懂题 → 找思路 → 分步算 → **验算** → 给结论 → 举一反三
- **必须验算才允许给答案**，两次结果不一致必须重做
- 禁止编造公式、定理、年份、课文出处
- 图片要先念出题目内容再讲

想改成自己家的风格，点左侧「老师人设 / 提示词」直接改，点「恢复默认」可以还原。

## 语音来源：本地 / 微软在线

听写页新增两个下拉框：

| 下拉框 | 选项 | 说明 |
| --- | --- | --- |
| 语音 | **微软在线（默认）** | 微软云希，音质明显好，需要联网 |
| | 本地(浏览器) | 强制用系统自带 TTS，不联网也能用 |
| 音色 | **云希(中文男声)** | 微软 zh-CN-YunxiNeural |
| | Andrew(英文男声) | 微软 en-US-AndrewMultilingualNeural |
| | 自动按语言选 | 中文用云希，英文用 Andrew |

用的是微软 Edge「大声朗读」的免费接口，**不需要注册、不需要 key、不需要登录**。
在线模式下语速滑块直接作用到云端合成（60% ~ 170%），不是简单变速。

小提示：
- **默认就是微软在线**。断网或微软接口失败时，会自动退回本地语音，状态栏会写明原因。
- 首次打开会弹一次使用说明，里面有给豆包用的提示词和「复制」按钮。
- 没声音先点右上角 **「?」**，里面会写明当前到底用的是本地还是在线、最后错误是什么。

## 预缓存：按 5 个一组

一边读一边在后台把**后面 5 个词**的音频提前合成好，换卡几乎无延迟。
每走到第 5、10、15…个词时，自动续下一组。改语速或换音色会重新预取。

## 日志：导入到词表

「日志」页选中某条听写记录（选中是**浅蓝色**），点「导入到词表」，
就会把那条记录的完整词表放回「词表」页，直接点生成卡片就能重听。

「词表」页还有 **粘贴剪贴板** 按钮，一键把剪贴板内容贴进来（已在有内容的输入框里时是追加）。

## 重要：一定要用 Chrome

测试结论：华为自带浏览器语音正常；小米/OPPO 自带浏览器语音发不出声（不报错）；
**换成 Chrome 全部正常**。微信/QQ 内置浏览器也不行。

没声音时点右上角 **「?」** 看诊断。

## 听写规则（重要）

**听写过程中卡片永远是遮挡的**，只有「看提示」能打开 3 秒：

| 操作 | 听写中行为 |
| --- | --- |
| 点击卡片 | **只切换位置，不打开内容** |
| 看提示3秒 | 唯一能打开卡片的按钮，打开 3 秒后自动恢复 |
| 再读一次 | 只朗读，不显示任何文字 |
| 试听 | 只朗读，不显示任何文字 |

状态栏也不会显示词内容，避免泄漏答案。

## 防误触

已禁用下拉刷新（页面顶部继续下滑不会刷新，卡片不会丢）：
CSS `overscroll-behavior:none` + JS 拦截 touchmove。

## 导入词表

日志页「导入词表」支持：

| 文件 | 说明 |
| --- | --- |
| `.txt` | 纯文本，按空格/标点切词 |
| `.csv` | 跳过表头，取词表列 |
| `.json` | 词数组，或本程序导出的日志 |

## 自动下一个

打开「自动下一个」后，读完会自动跳到下一张。间隔可选：

| 挡位 | 说明 |
| --- | --- |
| 1 秒 | 熟练后快节奏 |
| **3 秒（默认）** | 够写一个词 |
| 6 秒 | 低年级 / 长词 |
| 9 秒 | 很慢，手写慢的孩子 |

读完后状态栏会显示「读完，等 N 秒后自动下一个…」，期间可以随时手动按下一个跳过等待。

## 卡片

每行固定 4 个，尺寸统一（110×56）。遮挡时点数按字数：

- 1–2 个字 → 2 个点
- 3 个字 → 3 个点
- 4 个字及以上 → 4 个点

## 自动下一个的间隔

点「看提示」会响，音量 0.63（比最响低 30%），三连音上行。
可在「提示音」开关关闭。
