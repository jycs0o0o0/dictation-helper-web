# 听写助手 网页版

单个 HTML 文件，手机上用浏览器打开就能用。

在线版直接打开：<https://jycs0o0o0.github.io/dictation-helper-web/>

## 语音来源：本地 / 微软在线

听写页新增两个下拉框：

| 下拉框 | 选项 | 说明 |
| --- | --- | --- |
| 语音 | **微软在线（默认）** | 微软云希，音质明显好，需要联网 |
| | 本地(浏览器) | 强制用系统自带 TTS，不联网也能用 |
| 音色 | **云希(中文男声)** | 微软 zh-CN-YunxiNeural |
| | Andrew(英文男声) | 微软 en-US-AndrewMultilingualNeural |
| | 自动按语言选 | 中文用云希，英文用 Andrew |

用的是微软 Edge「大声朗读」的免费接口，**不需要注册、不需要 key、不需要登录**。
在线模式下语速滑块直接作用到云端合成（60% ~ 170%），不是简单变速。

小提示：
- **默认就是微软在线**。断网或微软接口失败时，会自动退回本地语音，状态栏会写明原因。
- 首次打开会弹一次使用说明，里面有给豆包用的提示词和「复制」按钮。
- 没声音先点右上角 **「?」**，里面会写明当前到底用的是本地还是在线、最后错误是什么。

## 预缓存：按 5 个一组

一边读一边在后台把**后面 5 个词**的音频提前合成好，换卡几乎无延迟。
每走到第 5、10、15…个词时，自动续下一组。改语速或换音色会重新预取。

## 日志：导入到词表

「日志」页选中某条听写记录（选中是**浅蓝色**），点「导入到词表」，
就会把那条记录的完整词表放回「词表」页，直接点生成卡片就能重听。

「词表」页还有 **粘贴剪贴板** 按钮，一键把剪贴板内容贴进来（已在有内容的输入框里时是追加）。

## 重要：一定要用 Chrome

测试结论：华为自带浏览器语音正常；小米/OPPO 自带浏览器语音发不出声（不报错）；
**换成 Chrome 全部正常**。微信/QQ 内置浏览器也不行。

没声音时点右上角 **「?」** 看诊断。

## 听写规则（重要）

**听写过程中卡片永远是遮挡的**，只有「看提示」能打开 3 秒：

| 操作 | 听写中行为 |
| --- | --- |
| 点击卡片 | **只切换位置，不打开内容** |
| 看提示3秒 | 唯一能打开卡片的按钮，打开 3 秒后自动恢复 |
| 再读一次 | 只朗读，不显示任何文字 |
| 试听 | 只朗读，不显示任何文字 |

状态栏也不会显示词内容，避免泄漏答案。

## 防误触

已禁用下拉刷新（页面顶部继续下滑不会刷新，卡片不会丢）：
CSS `overscroll-behavior:none` + JS 拦截 touchmove。

## 导入词表

日志页「导入词表」支持：

| 文件 | 说明 |
| --- | --- |
| `.txt` | 纯文本，按空格/标点切词 |
| `.csv` | 跳过表头，取词表列 |
| `.json` | 词数组，或本程序导出的日志 |

## 自动下一个

打开「自动下一个」后，读完会自动跳到下一张。间隔可选：

| 挡位 | 说明 |
| --- | --- |
| 1 秒 | 熟练后快节奏 |
| **3 秒（默认）** | 够写一个词 |
| 6 秒 | 低年级 / 长词 |
| 9 秒 | 很慢，手写慢的孩子 |

读完后状态栏会显示「读完，等 N 秒后自动下一个…」，期间可以随时手动按下一个跳过等待。

## 卡片

每行固定 4 个，尺寸统一（110×56）。遮挡时点数按字数：

- 1–2 个字 → 2 个点
- 3 个字 → 3 个点
- 4 个字及以上 → 4 个点

## 自动下一个的间隔

点「看提示」会响，音量 0.63（比最响低 30%），三连音上行。
可在「提示音」开关关闭。

## 其他功能

- 开始听写全部变灰，当前卡黄框高亮并自动朗读
- 上下切换、语速可调
- **自动下一个间隔 1 / 3 / 6 / 9 秒可选，默认 3 秒**
- 看提示次数记入日志
- 设置自动保存
